# Doodleblue

Small collection of HTML and CSS practice pages, including a multi-page campus events website.

## Project contents

### Root pages

- `index.html` - About-me profile page.
- `about.html` - College information page.
- `form.html` - HTML form controls example.
- `style.css` - Styles for the form controls page.

### Campus events site (`task1/`)

- `index.html` - Campus Events home page.
- `about.html` - About page.
- `events.html` - Events listing.
- `schedule.html` - Event schedule.
- `register.html` - Event registration page.
- `style.css` and `styles.css` - Site stylesheets.
- `script.js` - Site JavaScript.
- `navebar.html` - Empty placeholder file.

## Run locally

Open `index.html` or `task1/index.html` in a web browser. The pages are static and do not require a build step or local server.

Some pages load Bootstrap Icons from jsDelivr, which requires an internet connection.
